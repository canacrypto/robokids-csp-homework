# AP Computer Science Principles · Homework (GitHub Pages)

Homework only. Lessons, labs and mocks are on the RoboKids server.
Students can use these pages at any time. The Python tasks run inside the page (Skulpt, in `assets/`), so nothing needs installing. Scores show on screen, and students screenshot the result card for the teacher.

## Publish (one time, about 5 minutes)

1. On github.com, click **New repository**. Name it `robokids-csp-homework`, set it to **Public**, and click **Create repository**.
2. Click **uploading an existing file** and drag **everything inside this folder** (`index.html`, `assets`, `s01`…`s03`, `README.md`, `.nojekyll`) into the box. Then click **Commit changes**.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then click **Save**.
4. After 1–2 minutes the site is live at `https://YOUR-USERNAME.github.io/robokids-csp-homework/`.
5. Paste that address into `assets/config.js` on the RoboKids server, so the Homework buttons there link here.

Links to send students:

- All homework: `https://YOUR-USERNAME.github.io/robokids-csp-homework/`
- One session, for example Session 3: `https://YOUR-USERNAME.github.io/robokids-csp-homework/s03/homework.html`

## Adding the next unit

Use **Add file → Upload files** to upload the new `sNN` folders, and replace `index.html`.
