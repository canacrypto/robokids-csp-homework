Q1IF / ELSE
What is displayed?
x ← 4 y ← 9 IF(x > y) { DISPLAY(x) } ELSE { DISPLAY(y) }
A
9
B
4
C
4 9
D
x
Answer: 9. 4 > 9 is false, so the ELSE block displays y, which is 9. This code always displays the larger of the two numbers.
Q2Comparisons
What is displayed by DISPLAY((7 ≥ 7) AND (2 ≠ 2))?
A
false
B
true
C
7
D
Nothing: it causes an error
Answer: false. 7 ≥ 7 is true (7 is at least 7). 2 ≠ 2 is false. true AND false is false.
Q3Boolean logic
For which whole numbers n does this code display yes?
IF((n > 3) AND (n < 8)) { DISPLAY("yes") }
A
4, 5, 6 and 7 only
B
3, 4, 5, 6, 7 and 8
C
Every n greater than 3
D
4, 5, 6, 7 and 8
Answer: 4, 5, 6 and 7 only. Both parts must be true: n > 3 rules out 3 and below, and n < 8 rules out 8 and above. > and < do not include the end values.
Q4Nested IF
What is displayed?
a ← 3 b ← 10 IF(a > 5) { b ← b + a } ELSE { IF(b > 5) { b ← b - a } } DISPLAY(b)
A
7
B
13
C
10
D
3
Answer: 7. 3 > 5 is false, so the ELSE runs. Inside it, 10 > 5 is true, so b = 10 − 3 = 7. 13 comes from running the first block by mistake.
Q5Selection
Select two answers
num is a whole number, 0 or more. Which two code segments display even when num is even, and display nothing when it is odd?
A
IF(num MOD 2 = 0) { DISPLAY("even") }
B
IF(NOT (num MOD 2 = 1)) { DISPLAY("even") }
C
IF(num / 2 = 0) { DISPLAY("even") }
D
IF(num MOD 2 = 1) { DISPLAY("even") }
Answer: "MOD 2 = 0" and "NOT (MOD 2 = 1)". For whole numbers the remainder is either 0 or 1, so "not 1" means "0". num / 2 = 0 is only true for 0, and "MOD 2 = 1" picks the odd numbers.
