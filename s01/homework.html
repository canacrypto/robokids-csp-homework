Q1DISPLAY
What is displayed?
DISPLAY(2 + 3) DISPLAY("2 + 3")
A
5 2 + 3
B
5 5
C
2 + 3 2 + 3
D
5 and 2 + 3 on two lines
Answer: 5 2 + 3. Without quotes, 2 + 3 is worked out (5). With quotes it's text and is shown exactly as typed. Both DISPLAYs share one line.
Q2Sequencing
What is displayed?
a ← 1 b ← a a ← a + 5 DISPLAY(a) DISPLAY(b)
A
6 1
B
6 6
C
1 6
D
1 1
Answer: 6 1. b gets a copy of a's value (1) on line 2. Line 3 changes a to 6 but doesn't touch b. Trace table: a = 1, b = 1, a = 6.
Q3Block form
What does this program display?
level ← 2
level ← level * 5
DISPLAY("Level")
DISPLAY(level)
A
Level 10
B
Level 2
C
Level 7
D
level 10
Answer: Level 10. level starts at 2 and is multiplied by 5. The text "Level" (capital L, in quotes) is displayed exactly as written, then the value 10.
Q4Building blocks
Which description matches selection?
A
Choosing which statements run, based on a condition
B
Running statements one after another in order
C
Repeating a group of statements
D
Storing a value in a variable
Answer: choosing which statements run, based on a condition. That's an IF. Running statements in order is sequencing, repeating is iteration, and storing a value is assignment.
Q5Sequencing

A programmer wants a code segment that displays 6. Which two code segments work?
A
x ← 3
x ← x * 2
DISPLAY(x)
B
x ← 4
x ← x + 2
DISPLAY(x)
C
x ← 2
DISPLAY(x)
x ← x + 4
D
x ← 6

Answer: 3 doubled, and 4 plus 2. Both store 6 before the DISPLAY. The segment that displays before adding 4 shows 2, and the one that adds 1 to 6 shows 7.

TASK 2 · CHALLENGE · ~15 MIN
Translate AP to Python

Write a Python program that displays exactly what this AP program displays. First write the output on paper by tracing coins, then check it with your code.

coins ← 5
DISPLAY("Coins:")
DISPLAY(coins)
coins ← coins + 7
DISPLAY("Now:")
DISPLAY(coins)
coins ← coins * 2
DISPLAY("Doubled:")
DISPLAY(coins)
Expected output
Coins: 5 Now: 12 Doubled: 24
Every DISPLAY becomes print(..., end=" "). For the very last one, use a plain print so the line ends neatly.
coins = 5
print("Coins:", end=" ")
print(coins, end=" ")
coins = coins + 7
print("Now:", end=" ")
print(coins, end=" ")
coins = coins * 2
print("Doubled:", end=" ")
print(coins)
TASK 3 · STRETCH · ~15 MIN
Unscramble the program

These six lines got scrambled. Put all six lines in an order that prints the expected output. Don't change, add or remove any line. There's only one order that works, so use trace tables to test your ideas. When it works, write the same program in AP pseudocode as # comments underneath.

print("Final speed:", speed)
speed = speed * 2
speed = 4
speed = speed - 3
print("Start speed:", speed)
speed = speed + 10
Expected output
Start speed: 4
Final speed: 25
speed must start at 4 and be printed straight away. To reach 25 from 4 with +10, ×2 and −3, try working backwards: 25 + 3 = 28, and 28 ÷ 2 = 14.
