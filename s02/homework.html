Which two expressions evaluate to 2?
A
14 MOD 4
B
8 / 4
C
4 MOD 2
D
10 / 4
Answer: 14 MOD 4 and 8 / 4. 14 = 3 × 4 + 2, so the remainder is 2, and 8 ÷ 4 = 2. 4 MOD 2 is 0 (no remainder), and 10 / 4 is 2.5.

Part B · Coding tasks

TASK 1 · WARM-UP · ~10 MIN
Temperature converter

Set c = 25. Calculate Fahrenheit with f = c * 9 / 5 + 32, then convert back with (f - 32) * 5 / 9, storing it in a new variable. Print all three lines. Let the code do every calculation.

Expected output
Celsius: 25
Fahrenheit: 77.0
Back to Celsius: 25.0
back = (f - 32) * 5 / 9. The brackets matter: without them, only the 32 gets multiplied.
c = 25
f = c * 9 / 5 + 32
back = (f - 32) * 5 / 9
print("Celsius:", c)
print("Fahrenheit:", f)
print("Back to Celsius:", back)
TASK 2 · CHALLENGE · ~15 MIN
Time machine

A robot ran for total = 3725 seconds. Print how long that is in hours, minutes and seconds, using only // and %. There are 3600 seconds in an hour. Then, as a # comment, write how you would get the hours in AP pseudocode (remember: AP has no //).

Expected output
3725 seconds = 1 h 2 min 5 s
hours = total // 3600. What's left is total % 3600 (125). Split that into minutes and seconds the same way, with 60.
total = 3725
hours = total // 3600
rest = total % 3600
minutes = rest // 60
seconds = rest % 60
print(total, "seconds =", hours, "h", minutes, "min", seconds, "s")
# AP: hours ← (total - total MOD 3600) / 3600
TASK 3 · STRETCH · ~15 MIN
Digit splitter

Set n = 472. Using only // and % (no strings!), pull out the hundreds, tens and ones digits. Print them, their sum, and the number with its digits reversed. Your code must still work if you change n to another 3-digit number, so test it with n = 905 too.

Expected output
Number: 472
Digits: 4 7 2
Sum: 13
Reversed: 274
n % 10 is the ones digit. n // 10 % 10 is the tens digit. n // 100 is the hundreds digit. Reversed = ones × 100 + tens × 10 + hundreds.
n = 472
hundreds = n // 100
tens = n // 10 % 10
ones = n % 10
print("Number:", n)
print("Digits:", hundreds, tens, ones)
print("Sum:", hundreds + tens + ones)
print("Reversed:", ones * 100 + tens * 10 + hundreds)
